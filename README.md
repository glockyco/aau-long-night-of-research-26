# The U27 Gazette

A bilingual SvelteKit archive for Station U27 at the Long Night of Research 2026: ninety-one webpages built by visitors in one evening with AI, presented as a newspaper-style Gazette.

Live site: <https://lnf26.glockyco.com>

## What this is

The U27 Gazette is the public archive for a hands-on programming station run by the Software Engineering Research Group (SERG) at the University of Klagenfurt (AAU) during the Long Night of Research 2026 in Klagenfurt. Visitors described ideas in everyday language. The station setup generated small HTML, CSS, and JavaScript webpages. This site gathers those pages as built and wraps them in a playful editorial print design.

The site includes:

- German and English landing pages
- a browsable archive of visitor-built webpages
- creation detail pages with original standalone HTML files
- the station tasks and prompt flow
- a small Gazette-style crossword
- team and colophon notes

## Tech stack

- SvelteKit 2 and Svelte 5
- TypeScript
- Vite
- SvelteKit static adapter
- Cloudflare Workers via Wrangler
- pnpm

## Project structure

```text
src/lib/i18n/              German and English site copy
src/lib/data/creations.ts  metadata for the archived creations
src/routes/[lang=lang]/    localized routes
creations/                 source HTML files for featured creations
static/raw/                generated vendored creation HTML
scripts/                   build-time image, capture, and vendoring scripts
```

`static/raw/` is generated during the build by `scripts/vendor-creations.ts`. Edit the source files in `creations/` and the metadata in `src/lib/data/creations.ts` instead.

## Local development

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

## Build and preview

Build the static site:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```

Use `pnpm preview` for smoke testing. A generic static file server does not exercise the localized SvelteKit routes correctly.

## Quality checks

```bash
pnpm check
pnpm lint
```

## Content workflow

- Update bilingual interface and article copy in `src/lib/i18n/de.ts` and `src/lib/i18n/en.ts`.
- Update archived creation metadata in `src/lib/data/creations.ts`.
- Keep generated raw files out of hand edits. `pnpm build` vendors the configured creation HTML into `static/raw/`.
- Build-time icons and social cards are generated by `scripts/generate-images.mjs`.

## Deployment

Deployments are handled through Wrangler:

```bash
pnpm run deploy
```

The deploy script runs a production build before publishing.
